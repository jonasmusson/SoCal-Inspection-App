# Field-test notes

Use this document only as a scratchpad template during the first shop-floor validation. Do not copy test comments into customer-facing finding notes unless they are actually vehicle findings.

## Section feedback
For each section, capture:
- What felt natural
- What was confusing
- What took too many taps
- What the technician skipped or wanted to skip
- Any camera/video issue
- Any timer concern
- Any wording that did not match how the shop talks

## End-of-test questions
- Did the inspection flow match the order the technician naturally works around the car?
- Did required evidence feel appropriate or annoying?
- Did any save, reload, navigation, or background-phone action lose data?
- Was it obvious when the timer was running, paused, or resumed?
- Was manager review faster than interpreting handwritten notes?
- Did the finished report tell the same story the technician intended?
