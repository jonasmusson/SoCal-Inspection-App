# Inspection field-test feedback

Use the existing per-section Notes field for the first field test so feedback is captured while it is fresh without adding a temporary database column.

Suggested prefix for test-only workflow feedback:

`[FIELD TEST] `

Examples:
- `[FIELD TEST] Camera button was easy to find.`
- `[FIELD TEST] Too many taps to record a leaking hose.`
- `[FIELD TEST] I expected the timer to pause when I backed out.`

Keep actual vehicle-condition observations in the finding-level observation/impact/recommended-action fields. This convention is temporary and should be removed or replaced after the first test if a dedicated feedback surface proves useful.
